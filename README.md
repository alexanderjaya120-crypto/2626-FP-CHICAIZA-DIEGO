## Objetivo

Este programa permite gestionar la reserva de asientos de una pequeña sala de cine de 3 filas por 4 columnas.

Cada asiento se representa mediante un valor numérico:

- `0` = asiento libre
- `1` = asiento reservado

El programa solicita al usuario la fila y la columna del asiento que desea reservar, modifica la matriz y posteriormente muestra el estado completo de la sala.

## Tecnologías utilizadas

- Python 3

## Cómo ejecutar el programa

1. Descargar o clonar este repositorio.
2. Abrir una terminal en la carpeta del proyecto.
